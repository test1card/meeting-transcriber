# Приватность и данные

## Локальный режим

В локальном режиме аудио, видео, стенограмма и документы остаются на компьютере.
Сетевой запрос к языковой модели не выполняется. Для работы нужны установленные
локальные компоненты WSL, STT и Ollama.

## DeepSeek

DeepSeek — отдельный режим с явным подтверждением. Аудио и видео не отправляются:
наружу уходит только текст стенограммы. Программа не содержит чужого API-ключа.
Чтобы включить режим, администратор задаёт собственную переменную Windows
`DEEPSEEK_API_KEY` и перезапускает приложение.

## Что не входит в GitHub-репозиторий

- `.env` и токены Hugging Face;
- пользовательские записи и документы из `outputs`;
- виртуальные окружения и кэши моделей;
- локальные пути разработчика.

В репозитории находится только исходный код, тестовые синтетические данные,
лицензии, установщик и документация.

Исходный код приложения распространяется по MIT. Сторонние библиотеки, MOSS,
WhisperX, Qwen, Gemma и сервис DeepSeek сохраняют собственные лицензии и условия.
Перед корпоративным использованием проверьте их требования.
