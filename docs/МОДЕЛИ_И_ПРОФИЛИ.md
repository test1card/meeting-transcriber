# Модели и профили

Мастер установки сначала определяет доступные ресурсы компьютера: VRAM, RAM,
свободное место, тип устройства и наличие CUDA. Рекомендация строится по
классу ресурсов, а не по названию одной видеокарты.

| Профиль | Для чего | Практический смысл |
| --- | --- | --- |
| **Локально — сильный и эффективный** | Gemma 4 12B + полный STT-контур | Основной локальный вариант для 16 ГБ VRAM; конфиденциальные данные не уходят наружу |
| **DeepSeek API** | DeepSeek V4 Flash для текстовой обработки | Лучшее качество редакторского протокола; используется только с собственным ключом |
| **Локально — быстрый черновик** | Gemma 4 e4b | Быстрое предварительное чтение, не рекомендуемый финальный протокол |
| **Локально — максимум** | Gemma 4 26B и более тяжёлые варианты | Экспериментальный режим с большим расходом RAM/времени; устойчивого выигрыша над 12B на текущем тесте не показал |

## Обязательный STT-контур

- **MOSS-Transcribe-Diarize 0.9B** — распознавание с опорой для говорящих и
  временных границ.
- **ECAPA-TDNN** — голосовые эмбеддинги для сопоставления говорящих.
- **WhisperX large-v3 + русский aligner** — точные слова и выравнивание.
- **Qwen3-ASR 1.7B + ForcedAligner** — независимая проверка чтения и границ.

Веса моделей не входят в установщик. Мастер скачивает только выбранный профиль,
а лицензии самих моделей перечислены в `THIRD_PARTY_NOTICES.md`.

## Как выбрать

Если запись конфиденциальная, выбирайте локальный профиль и Gemma 12B. Если
допустима отправка текста стенограммы в DeepSeek и нужен максимально аккуратный
протокол, используйте DeepSeek V4 Flash. Gemma e4b оставляйте для черновиков.
