# Консенсус нескольких STT-результатов

Этап консенсуса принимает два или более `transcript.json` и создаёт одну
проверенную каноническую стенограмму с полным аудитом решений.

## Правило якоря

Один результат выбирается якорем. Его таймкоды и говорящие неизменяемы. Для каждого
якорного фрагмента конвейер собирает только те варианты других STT, которые
пересекаются с ним по времени.

Точные совпадения проходят без вызова языковой модели. Разногласия отправляются
судье небольшими пакетами. Судья может восстановить только произнесённый текст:
он не должен пересказывать, переводить, придумывать контекст, менять говорящего
или менять таймкод.

Русский промпт сохраняет английские имена, идентификаторы, названия файлов,
команды, числа, отрицания и технические термины.

## Запуск

Скопируйте `glossary.example.txt` в `glossary.txt` и добавьте имена сотрудников,
проекты, сокращения и специальную лексику.

```powershell
.\consensus.ps1 `
  -Transcripts @(
    ".\runs\moss\transcript.json",
    ".\runs\qwen\transcript.json",
    ".\runs\whisperx\transcript.json"
  ) `
  -Labels "moss,qwen,whisperx" `
  -Anchor "moss" `
  -Glossary ".\glossary.txt"
```

В качестве якоря выбирайте результат с наиболее надёжной диаризацией. Текст
сравнивается только в пределах совпадающих временных интервалов.

Для конфиденциальной встречи отключите DeepSeek:

```powershell
.\consensus.ps1 `
  -Transcripts @(".\moss.json", ".\qwen.json", ".\whisperx.json") `
  -Labels "moss,qwen,whisperx" `
  -Anchor "moss" `
  -JudgeModel "gemma4:12b" `
  -NoDeepSeek
```

Подробная архитектура и границы детерминизма описаны в
[`docs/АРХИТЕКТУРА.md`](docs/АРХИТЕКТУРА.md).
