# Материалы встреч — инструкция пользователя

## Быстрый старт

Распакуйте архив в удобную папку и запустите
`Материалы встреч_0.1.16_x64-setup.exe`. Файл `SHA256SUMS.txt` позволяет
проверить, что установщик не повредился при скачивании.

## Что делает программа

Программа принимает аудио или видео продолжительностью до пяти часов, локально
распознаёт русскую речь с отдельными английскими словами, обязательно разделяет
говорящих и автоматически создаёт четыре документа Word:

1. протокол совещания;
2. полную стенограмму с временными метками и говорящими;
3. редакционную стенограмму без речевого мусора, близкую к оригиналу;
4. сокращённую смысловую стенограмму без повторов.

## Первый запуск

1. Нужны Windows 10/11 x64, интернет и права администратора для установки
   системных компонентов. Может потребоваться перезагрузка из-за WSL2.
2. В мастере выберите рекомендуемый профиль. Для локальной работы по умолчанию
   предлагается Gemma 12B. Мастер проверит компьютер, установит недостающие
   компоненты и скачает выбранные модели.
3. Для рекомендуемого локального профиля предусмотрите примерно 22 ГБ загрузок
   и не менее 40 ГБ свободного места после установки. Практический рекомендуемый
   уровень — NVIDIA GPU с 16 ГБ VRAM и 48–64 ГБ RAM; мастер умеет предложить
   облегчённые или более тяжёлые варианты для другого оборудования.
4. Добавьте запись, выберите папку результата и нажмите «Создать документы».

Установка повторяемая: уже установленные компоненты пропускаются, сбои отдельных
моделей собираются в итоговый список и не должны останавливать остальные шаги.

## Локальный режим и DeepSeek

Без API-ключа программа автоматически работает локально, а карточка DeepSeek
недоступна. Чтобы разрешить API-режим, администратор должен добавить собственную
пользовательскую переменную среды Windows `DEEPSEEK_API_KEY` и перезапустить
программу. Ключ не показывается в интерфейсе и не записывается в документы или
логи. Перед каждым заданием пользователь явно подтверждает отправку; наружу
передаётся только текст стенограммы, не аудио или видео.

В дистрибутиве нет API-ключей, токенов Hugging Face, записей совещаний,
стенограмм, готовых документов и персональных путей разработчика.

## Важные замечания

- Установщик пока не подписан коммерческим сертификатом. Windows SmartScreen
  может показать предупреждение «Неизвестный издатель»; для бесшовного
  корпоративного развёртывания нужен сертификат подписи кода организации.
- Веса моделей скачиваются при первом развёртывании и имеют собственные условия
  использования. Подробности перечислены в `THIRD_PARTY_NOTICES.md`.
- Для точных имён людей вместо «Говорящий 1» можно заполнить известные имена в
  интерфейсе; сама идентификация/диаризация говорящих обязательна всегда.
- Локальная обработка длинной записи может занимать значительно больше времени,
  чем длительность записи, в зависимости от GPU, RAM и выбранной модели.

## Проверка файла

В PowerShell в папке релиза выполните:

```powershell
Get-FileHash '.\Материалы встреч_0.1.16_x64-setup.exe' -Algorithm SHA256
```

Полученная строка должна совпасть с `SHA256SUMS.txt`.

Исходный код приложения распространяется по лицензии MIT. Сторонние компоненты
и модели сохраняют собственные лицензии и условия.
